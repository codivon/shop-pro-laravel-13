# راهنمای استفاده — باشگاه مشتریان (CustomerClub v1.0.0)

## ۱) این پکیج کارش چیه؟
سه موتور وفاداری که به هم وصل‌اند و همه به **کیف پول هسته** ختم می‌شوند:

1. **امتیاز وفاداری** — مشتری با خرید/ثبت‌نام/نظر/تولد امتیاز می‌گیرد و می‌تواند آن را به اعتبار کیف پول تبدیل کند.
2. **کارت هدیه** — شما کد صادر می‌کنید، مشتری فعال می‌کند، مبلغ مستقیم به کیف پولش می‌رود.
3. **معرفی دوستان** — لینک دعوت + سطوح برنزی/نقره‌ای/طلایی با پاداش یک‌بارمصرف.

> **هیچ فایلی از هسته پچ نشده** — اتصال‌ها: رویدادهای `OrderPaid` و `Registered`، Observer تأیید نظر، و مدل‌های `Wallet`/`WalletHistory` خود هسته.

## ۲) شروع سریع
1. **تنظیمات** (باشگاه مشتریان → تنظیمات): کلید امکانات را روشن/خاموش کنید؛ نرخ تبدیل (`redeem_rate_toman`) و حداقل امتیاز را تعیین کنید.
2. **قوانین امتیاز**: پلهٔ مبلغ خرید (پیش‌فرض هر ۱۰٬۰۰۰ تومان = ۱ امتیاز) و امتیازهای ثابت را تنظیم کنید — هر قانون کلید فعال/غیرفعال خودش را دارد.
3. **کارت‌های هدیه**: دستهٔ اول را صادر کنید؛ CSV کدها در `storage/app/giftcards` ذخیره می‌شود.
4. **معرفی دوستان**: گزارش معرف‌ها و سطوح را رصد کنید.
5. **دفتر امتیازها**: تمام رویدادهای امتیاز با فیلتر نوع/رویداد/مشتری.

## ۳) کلیدهای تنظیمات

| کلید | پیش‌فرض | توضیح |
|------|---------|-------|
| `club_enabled` | روشن | کلید اصلی — خاموشی = پنهان‌شدن کل بخش مشتری + توقف رویدادها |
| `loyalty_enabled` | روشن | موتور امتیاز |
| `giftcards_enabled` | روشن | کارت هدیه |
| `referral_program_enabled` | روشن | بخش معرفی + صفحهٔ فرود |
| `referral_bonus_enabled` | روشن | پاداش سطوح |
| `redeem_rate_toman` | ۱۰۰۰ | هر امتیاز چند تومان |
| `redeem_min_points` | ۱۰۰ | حداقل امتیاز تبدیل |
| `points_expiry_days` | ۳۶۵ | انقضای امتیاز (۰ = بی‌انقضا) |

## ۴) رفتارهای تضمین‌شده
- **Idempotency**: هر منبع امتیاز (شمارهٔ سفارش، شناسهٔ نظر، کاربر، سال تولد، شناسهٔ سطح) فقط یک‌بار امتیاز می‌دهد.
- **FIFO کسر**: لاتِ نزدیک‌تر به انقضا اول مصرف می‌شود؛ NULLها آخر.
- **Audit کامل**: همهٔ کسرها (تبدیل/انقضا/تنظیم دستی) یک سطر منفی در دفتر دارند؛ دلیل تنظیم دستی اجباری است.
- **ضد رقابت**: همهٔ تغییر موجودی‌ها داخل تراکنش با `lockForUpdate`.
- **کارت هدیه یک‌بارمصرف**: قفل تراکنشی روی ردیف کارت؛ مصرف‌شده/غیرفعال/منقضی پیام دقیق دارد.

## ۵) کامندها و زمان‌بندی
| کامند | زمان‌بندی | کار |
|-------|-----------|-----|
| `customerclub:install-permissions` | دستی (نصب‌کننده) | نصب پرمیژن‌ها + seedDefaults idempotent |
| `customerclub:expire-points` | روزانه ۰۳:۱۵ | انقضای لات‌های سررسیده |
| `customerclub:birthday-points` | روزانه ۰۷:۰۰ | پاداش تولد (شمسی/میلادی هر دو پوشش داده می‌شود) |

## ۶) پنل مشتری
- مسیر: `profile/club` — موجودی، تبدیل امتیاز، کارت هدیه، لینک دعوت، دفتر امتیاز من.
- راهنمای مشتری: `profile/club/guide` — از بنر درون‌صفحه‌ای (نه منوی سایدبار — درس فاز ۸۹).
- صفحهٔ فرود دعوت: `referral/{code}` — عمومی؛ کد نامعتبر = ۴۰۴.

## ۷) عیب‌یابی
- **منوی پنل دیده نمی‌شود؟** `modules_statuses.json` → `"CustomerClub": true` و کش‌ها را خالی کنید؛ منو به نصب+فعال‌بودن وابسته است نه لایسنس (فاز ۸۵).
- **امتیاز خرید نیامد؟** قانون `purchase` فعال است؟ `loyalty_enabled` روشن است؟ سفارش بالای پله بود؟
- **کارت فعال نشد؟** پیام دقیق نشان داده می‌شود (مصرف‌شده/غیرفعال/منقضی/ناموجود).
