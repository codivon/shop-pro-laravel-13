# باشگاه مشتریان (CustomerClub) — v1.0.0

پکیج وفاداری مشتری برای فروشگاه‌ساز ShopPro: **امتیاز وفاداری** (لات‌محور FIFO) + **کارت هدیه** (متصل به کیف پول هسته) + **معرفی دوستان** (توسعهٔ سیستم Referral هسته — بدون هیچ پچ دستی در هسته).

> 🔒 **الگوی شخصی‌سازی:** هر امکان این پکیج یک کلید فعال/غیرفعال مستقل در تنظیمات دارد — حداقلِ قابل کنترل بودن هر قابلیت، همیشه برقرار است.

## امکانات

### 🌟 امتیاز وفاداری
- مدل **لات (Lot)**: هر بستهٔ امتیاز با تاریخ انقضای خودش؛ موجودی = `SUM(remaining)`
- کسر **FIFO**: نزدیک‌ترین انقضا اول (NULLها آخر) — عین رفتار صرفهٔ مشتری
- **Idempotent**: هر منبع (سفارش/نظر/ثبت‌نام/سال تولد) فقط یک‌بار امتیاز می‌دهد — دیسپچ دوبارهٔ رویداد اثری ندارد
- ۴ قانون قابل تنظیم از پنل: خرید (پله‌ای)، ثبت‌نام، تأیید نظر (Observer پکیجی)، تولد (کامند شبانه با مبدل شمسی خودکفا)
- **انقضای خودکار** (`points_expiry_days` + کامند `customerclub:expire-points` روزانه ۰۳:۱۵)
- **تبدیل به کیف پول هسته** با `WalletHistory` (نرخ/حداقل قابل تنظیم — audit یکپارچه)
- تنظیم دستی ادمین (مثبت/منفی) با **دلیل اجباری**

### 🎁 کارت هدیه
- صدور دسته‌ای تا ۵۰۰ کارت با کد `CC-XXXX-XXXX` + خروجی CSV
- فعال‌سازی مشتری ← **شارژ مستقیم کیف پول هسته** با قفل تراکنشی (ضد مصرف دوباره در رقابت)
- غیرفعال‌سازی ادمین + وضعیت‌ها: فعال/مصرف‌شده/غیرفعال

### 🤝 معرفی دوستان (بدون پچ هسته)
- صفحهٔ فرود عمومی `referral/{code}` → ریدایرکت به فلوی ثبت‌نام هسته با `?ref=` (عین هسته) + ۴۰۴ کد نامعتبر
- بخش معرفی در پنل مشتری: لینک + کپی + آمار + نوار پیشرفت سطوح
- پاداش یک‌بارمصرف سطوح **برنزی/نقره‌ای/طلایی** با «خرید موفق» دعوت‌شده

### ⚙️ کلیدهای تنظیمات (پنل: باشگاه مشتریان → تنظیمات)

| کلید | کنترل |
|------|-------|
| `club_enabled` | کلید اصلی — خاموشی = پنهان‌شدن کل بخش مشتری + توقف رویدادهای خودکار |
| `loyalty_enabled` | موتور امتیاز (کسب + تبدیل) |
| `giftcards_enabled` | کارت هدیه |
| `referral_program_enabled` | بخش معرفی + صفحهٔ فرود دعوت |
| `referral_bonus_enabled` | پاداش سطوح معرفی |
| قوانین `is_active` | هر یک از ۴ رویداد امتیاز جداگانه |
| `redeem_rate_toman` | نرخ تبدیل هر امتیاز به تومان |
| `redeem_min_points` | حداقل امتیاز تبدیل |
| `points_expiry_days` | انقضای امتیاز (۰ = بی‌انقضا) |

## نصب
1. محتوای این مخزن در `Modules/CustomerClub` قرار می‌گیرد.
2. `composer dump-autoload`
3. `php artisan module:migrate CustomerClub` (مایگریشن‌ها گارد `hasTable` دارند)
4. `php artisan customerclub:install-permissions`
5. فعال‌سازی در `modules_statuses.json` (نصب‌کنندهٔ هاست خودکار انجام می‌دهد)
